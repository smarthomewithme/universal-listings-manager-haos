# Third-party notices

Python libraries are listed in `olx_manager/requirements.txt`. Installation preserves their license files in the installed distribution metadata. See the [Docker Official Image for Python](https://github.com/docker-library/python) for the base image license and source.

[Waldisurfer/olx-automation](https://github.com/Waldisurfer/olx-automation) was reviewed as a comparison project during v1.0. The implementation is based on the user's prototype and did not copy upstream source. The [original MIT notice](docs/licenses/olx-automation-MIT.txt) is retained for attribution.
